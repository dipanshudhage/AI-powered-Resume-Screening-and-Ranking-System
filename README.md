
# AI-Powered Resume Screening and Ranking System

## 🚀 Project Overview
This project was developed as part of my **Internship under the AICTE TechSaksham Program**, a joint CSR initiative by **Microsoft & SAP**, implemented by Edunet Foundation.  
It leverages **Artificial Intelligence (AI)** and **Natural Language Processing (NLP)** to automate and enhance the hiring process by:
- Extracting key details from resumes
- Ranking candidates based on job-fit
- Promoting fair and unbiased recruitment

---

## 📌 Key Features
- ✅ Resume Parsing from PDFs
- ✅ Named Entity Recognition (NER) for Skill Extraction
- ✅ Resume Ranking using AI Models
- ✅ Real-Time Candidate Scoring
- ✅ Clean Frontend with Streamlit Integration

---

## 🛠️ Tech Stack Used
- Python
- spaCy, Scikit-learn, BERT (NLP & ML)
- PyMuPDF for PDF Parsing
- Streamlit for UI
- Flask for Backend API

## 🖥️ How to Run the Project
1. Clone the repository:
```bash
git clone https://github.com/YourUsername/AI-Resume-Screening-System.git
```
2. Install dependencies:
```bash
pip install -r requirements.txt
```
3. Run the application:
```bash
streamlit run resume_ranking_advanced.py
```
4. Upload resumes and provide job description input.
